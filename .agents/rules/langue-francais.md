# Langue : tout en français

**Règle.** Chaque message à benglut est en français, sans exception : comptes rendus de fin de
tâche, rapports Vinted, tableaux, comparatifs, notes de progression entre deux outils. Docs et
textes de l'interface en français ; identifiants de code en anglais. Seuls le code, les
commandes, les chemins et les citations étrangères restent tels quels.

**Pourquoi.** Exigence du cahier des charges initial (2026-08-08). Le 2026-10-10, quatre réponses
sont parties en anglais dans la même journée ; benglut : « Parle-moi en français, mets ça dans
tes règles ».

**Comment.** Le risque est maximal après une longue suite d'appels d'outils : relire la langue
de la réponse avant de l'envoyer.
